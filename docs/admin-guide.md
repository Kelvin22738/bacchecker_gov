## Admin Overview

### Admin Types

#### GTEC Administrator
- **Scope**: Tertiary education institutions only
- **Primary Role**: Oversee university and college verification processes
- **Key Responsibilities**:
  - Manage tertiary institutions
  - Process academic verification requests
  - Generate verification reports
  - Monitor educational compliance

#### BacChecker System Administrator
- **Scope**: Entire platform (all government institutions)
- **Primary Role**: Full system administration
- **Key Responsibilities**:
  - Manage all institution types
  - System configuration and maintenance
  - Global template management
  - Platform security oversight

### Admin Dashboard Features
- **System Overview**: Real-time platform statistics
- **Institution Status**: Health and activity monitoring
- **Request Monitoring**: Cross-institutional request tracking
- **Performance Metrics**: SLA compliance and processing times
- **System Alerts**: Critical notifications and recommendations

## Institution Management

### Adding New Institutions

#### For GTEC Administrators (Tertiary Institutions)
1. **Navigate to Institutions Management**
2. **Click "Add Institution"**
3. **Fill Institution Details**:
   - Institution name and acronym
   - Institution type (university, technical, college, etc.)
   - Contact information (email, phone, address)
   - Basic statistics (students, faculty, established year)
4. **Send GTEC Onboarding**:
   - System generates simplified onboarding link
   - Institution receives GTEC-branded setup process
   - Pre-configured with educational verification services

#### For BacChecker Administrators (All Institutions)
1. **Navigate to Government Institutions Management**
2. **Click "Add Institution"**
3. **Configure Institution Type**:
   - Security Services (Police, Immigration)
   - Judicial Services (Courts, Legal)
   - Government Ministry
   - Regulatory Body
4. **Send Full Onboarding**:
   - Complete BacChecker setup wizard
   - Full service configuration options
   - Custom template creation tools

### Institution Onboarding Process

#### GTEC Simplified Onboarding
1. **Welcome & Introduction**: GTEC-branded welcome screen
2. **Institution Verification**: Confirm pre-filled details
3. **Branding Setup**: Upload logo and set colors
4. **Academic Programs**: Add courses and programs
5. **Service Configuration**: Pre-configured verification services
6. **Launch**: Immediate access to verification dashboard

#### BacChecker Full Onboarding
1. **Welcome**: Platform introduction
2. **Institution Profile**: Complete profile setup
3. **Service Configuration**: Custom service creation
4. **Document Templates**: Template upload and creation
5. **Digital Signatures**: Signature and seal setup
6. **User Roles**: Permission and role configuration
7. **Registry Builder**: Custom data registry creation
8. **Review & Launch**: Final configuration review

### Managing Existing Institutions
- **View Institution Profiles**: Detailed institution information
- **Monitor Activity**: Request processing and user activity
- **Update Configurations**: Modify settings and services
- **Manage Users**: Add, remove, and configure institution users
- **View Analytics**: Institution-specific performance metrics

## User Management

### GTEC User Management
GTEC administrators can manage their own team:

1. **Access Settings → User & Department Management**
2. **Department Management**:
   - Create departments (e.g., "Verification Unit", "Quality Assurance")
   - Assign department heads
   - Organize team structure

3. **User Invitation**:
   - Click "Invite User"
   - Enter user details (name, email, role, department)
   - Choose role: GTEC Admin or GTEC Agent
   - System sends invitation email

4. **User Roles**:
   - **GTEC Admin**: Full GTEC system access
   - **GTEC Agent**: Limited verification processing access

### System-Wide User Management
BacChecker administrators can manage all platform users:

1. **Institution User Management**:
   - View users across all institutions
   - Reset passwords and manage access
   - Monitor user activity and login history

2. **Role Assignment**:
   - Assign platform-wide roles
   - Configure cross-institutional permissions
   - Manage system administrator access
